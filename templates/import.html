Importação inicial via Excel

O Excel é usado apenas para entrada inicial e ajustes. Os dados são salvos no banco de dados.

Voltar
Apenas arquivos Excel são aceitos. Certifique-se de incluir as colunas obrigatórias.

Colunas aceitas no Excel

Obrigatórias: nome, categoria, unidade. As demais são opcionais.

Coluna Obrigatória Descrição Exemplo
nome Sim Nome do produto Parafuso 10mm
categoria Sim Categoria do produto Ferragens
unidade Sim Unidade de medida un, kg, m, L
marca Não Marca do produto Vonder, Tramontina
unidade_filial Não Unidade ou filial de estoque SP, RJ, Matriz
valor_unitario Não Valor unitário em R$ 12.50
quantidade Não Quantidade em estoque 150
quantidade_minima Não Quantidade mínima (alerta) 20
localizacao Não Localização física no estoque Prateleira A3
descricao Não Descrição complementar Parafuso sextavado galvanizado
observacoes Não Observações adicionais Fornecedor preferencial: XYZ
id Não ID interno (para atualizar registro existente) 42
